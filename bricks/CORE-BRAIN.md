# العقل المعماري والشبكة العصبية لمنظومة "خطي" (`CORE-BRAIN.md`)

منظومة «خطي» لإدارة خطوط النقل الدراسي الشهري في العراق مبنية على معمارية الأنوية السيادية المعزولة **B.R.I.C.K** (Bounded, Reliable, Immutable Cross-Layer Kernels) وفق الورقة البحثية v0.4 للباحث م. مسلم عقيل عبد الحسن العنزي.

---

## 1. الهيكل والطبقات (Architectural Layers)

1. **طبقة التطبيق والمسارات العامة (`src/app/`):**
   - الغلاف الهيكلي والخطوط العربية الهندسية (`layout.tsx`).
   - نقطة الدخول وبوابات الاستعراض التفاعلية (`page.tsx`).
   - نظام الهوية البصرية الصارم 8pt Grid و 60-30-10 (`globals.css`).

2. **طبقة المكونات والنظم الكاملة (`src/components/`):**
   - البوابات الثلاث المتكاملة: بوابة الطالب وولي الأمر، بوابة السائق وتوثيق الوثائق KYC، وغرفة القيادة المركزية للأسطول (`KhattiFullStackSystem.tsx`).
   - خوارزميات المطابقة العمياء، حجب أرقام الهواتف المشروط، وفلترة أوقات الدوام وأنواع السيارات.

3. **طبقة التتبع والخدمات اللحظية (`src/lib/`):**
   - العميل الموحد لقاعدة بيانات وحسابات Supabase Cloud (`supabaseClient.ts`).
   - جسر الاتصال اللحظي مع شرائح وأجهزة التتبع Traccar GPS WebSockets وبث الإحداثيات السلسة (`traccarWebSocket.ts`).

4. **طبقة قاعدة البيانات المكانية (`supabase/`):**
   - دوال التوزيع الجغرافي والفرز المكاني عبر إضافة PostGIS (`find_matching_drivers_for_student`).
   - جداول الحماية وعزل البيانات الصارم عبر سياسات Row-Level Security (RLS).

---

## 2. جدول الأنوية المعمارية السيادية B.R.I.C.K (Kernel Catalog)

| الرمز السيادي | اسم النواة المعمارية | النطاق الوظيفي | المسؤولية الحصرية ومحتوى النواة |
|---|---|---|---|
| **FE-CORE-01** | Core Shell & Optical Design | الواجهة العامة | الغلاف العام، خطوط النظام، الشبكة البصرية، والصفحة الرئيسية |
| **FE-TRANSPORT-01** | Portals & Line Matching | منظومة النقل | بوابات الطلاب، السائقين، والتحكم بالخطوط والمطابقة العمياء |
| **FE-TELEMETRY-01** | GPS Tracking & Telemetry | التتبع اللحظي | جسر WebSockets مع أجهزة Traccar وبث إحداثيات المركبات |
| **BE-DATA-01** | Supabase Backend & Auth | الخدمات الخلفية | العميل المركزي لقاعدة البيانات، الصلاحيات، والجداول المكانية |

## 3. المسلمات الحتمية المطبقة
- **Zero Orphans:** تغطية شاملة 100% لكافة ملفات `src/` بدون أي ملف يتيم.
- **Exclusive Ownership:** حظر الملكية المشتركة أو المزدوجة بين أي نواتين.
- **Privacy Invariant:** حجب أرقام وأسماء العائلات والطلبة عن السائق حتى إقرار التثبيت الرسمي.
- **Cryptographic State:** بصمات تشفيرية قطعية لكافة الملفات لمنع التراجعات الصامتة.
